# 🌍 TerraNova — Дневник путешественника & Экспедиционный блог

Современная адаптация веб-платформы под тематику **авторского блога о путешествиях, автономных экспедициях и путеводителях**.

```bash
/home/ruslan/up_web_89
```

Резервная копия предыдущего проекта вынесена во внешнюю директорию:
```bash
/home/ruslan/tailwind-mastery-day9-10 (симлинк: /home/ruslan/up_web_89_old)
```

---

## 🚀 Инструкция по запуску

Проект полностью настроен и готов к работе.

### 1. Переход в директорию проекта
```bash
cd /home/ruslan/up_web_89
```

### 2. Запуск локального сервера разработки (Dev Server)
```bash
npm run dev
```
Сервер запустится по адресу:
👉 **`http://localhost:3000`** (или открытом внешнем IP).

### 3. Сборка для продакшна (Production Build)
```bash
npm run build
```
Собранные оптимизированные файлы появятся в директории `dist/`.

### 4. Предпросмотр сборки (Preview)
```bash
npm run preview
```

## 🎨 Дизайн и стек технологий

- **Tailwind CSS 3.4+**: кастомные цвета `brand` (Ocean Teal) и `sunset` (теплый закатный янтарь), `@container` (container queries), glassmorphism (`.glass-card`), плавные скроллбары.
- **Vite 6**: молниеносный HMR и оптимизированный бандлинг.
- **Vue 3**: динамический компонент спонсорских и партнерских спецпроектов `AdSlot.vue`.
- **Dark / Light Mode**: адаптивная смена темы оформления с сохранением в `localStorage` и иконками солнца/луны.
- **Mobile First**: полностью отзывчивый дизайн от 320px до 4K-дисплеев.
