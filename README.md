# 🌍 TerraNova — Дневник путешественника & Экспедиционная платформа

Современная многостраничная веб-платформа (MPA) о путешествиях, автономных экспедициях, путеводителях и снаряжении на базе **Vite 6**, **Vue 3 (Composition API)** и **Tailwind CSS 3.4**. Все цены на сайте указаны в **белорусских рублях (BYN)**.

---

## 🚀 Инструкция по запуску

```bash
# 1. Установка зависимостей (если ещё не установлены)
npm install

# 2. Запуск локального сервера разработки (HMR)
npm run dev

# 3. Продакшн-сборка в папку dist/
npm run build

# 4. Предпросмотр собранного проекта
npm run preview
```

## 📘 Гайд по Vue 3 и Tailwind CSS (подготовка к защите)

### 1. Зачем вообще нужен Vue 3 и какую проблему он решает?

В обычном «ванильном» JavaScript (DOM-манипуляции через `document.querySelector`, `innerHTML`, `addEventListener`) при росте интерфейса код быстро превращается в «спагетти»: приходится вручную следить за тем, чтобы при изменении одной переменной обновились все нужные места на странице.

**Vue 3** — это прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов. Он решает три главные задачи:
1. **Реактивность (`ref`, `computed`, `watch`):** вы меняете данные (например, фильтр цены или массив сообщений чата), а Vue сам автоматически и точечно перерисовывает только нужные элементы DOM через **Virtual DOM**.
2. **Компонентный подход (SFC — Single-File Components, `.vue`):** интерфейс разбивается на независимые переиспользуемые блоки, где в одном файле лежат:
   - `<template>` — HTML-разметка с директивами (`v-for`, `v-if`, `v-model`, `@click`, `:class`);
   - `<script setup>` — логика на Composition API;
   - `<style>` — (опционально) стили компонента.
3. **Декларативность:** вместо «найди элемент по ID и вставь в него HTML» мы описываем, *как интерфейс должен выглядеть при текущем состоянии данных*.

### 2. Как Vue 3 устроен именно в этом проекте?

Проект собран через **Vite** с плагином `@vitejs/plugin-vue` (`vite.config.mjs`) в режиме **MPA (Multi-Page Application)** — у каждой HTML-страницы есть своя точка входа, а общие Vue-компоненты подключаются через единый модуль `src/js/main.js`.

В HTML-страницах ставятся лёгкие «якоря» (mount points), например:
- `<div data-vue-header ...></div>`
- `<div data-vue-hero-widget></div>`
- `<div data-vue-catalog></div>`

При загрузке страницы функция `initVueComponents()` в `src/js/main.js` находит эти элементы и монтирует в них нужные Vue-приложения через `createApp(Component, props).mount(el)`.

### 3. Зачем вообще нужен Tailwind CSS и в чём его плюсы?

**Tailwind CSS** — это **utility-first** CSS-фреймворк. Вместо того чтобы придумывать сотни имён классов в отдельных `.css`-файлах (`.card-header-left-title`), вы собираете дизайн прямо в разметке из атомарных классов: `flex`, `gap-4`, `p-6`, `rounded-3xl`, `bg-white/90`, `dark:bg-slate-900`.

Почему его выбирают в современных проектах:
1. **Единая дизайн-система из коробки:** отступы, радиусы, тени и шрифты подчиняются строгой шкале (`p-4`, `p-6`, `rounded-2xl`, `rounded-3xl`) — интерфейс выглядит аккуратно и согласованно.
2. **Адаптивность без медиа-запросов вручную:** префиксы `sm:`, `md:`, `lg:`, `xl:` позволяют сразу писать правила для мобильных и десктопов (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).
3. **Тёмная тема через префикс `dark:`:** достаточно добавить класс `.dark` на `<html>`, и все классы вида `dark:bg-slate-900 dark:text-white` срабатывают автоматически.
4. **Минимальный итоговый CSS:** при `npm run build` Tailwind сканирует только те классы, которые реально использованы в `.html` и `.vue` файлах, и вырезает всё лишнее (в итоге весь CSS проекта весит ~12–13 КБ в gzip!).

### 4. Как Tailwind CSS настроен и используется в TerraNova?

1. **Конфигурация (`tailwind.config.js`):**
   - `darkMode: 'class'` — переключение темы управляется классом `.dark` на `<html>` (и сохраняется в `localStorage`).
   - `content` — указаны пути `./index.html`, `./pages/**/*.html`, `./src/**/*.{html,js,ts,vue}`, чтобы Tailwind видел классы внутри всех Vue-компонентов.
   - **Кастомная природная палитра (`theme.extend.colors`):**
     - `brand` (океанический бирюзовый `#14b8a6`),
     - `sunset` (тёплый закатный оранжевый `#f97316`),
     - `forest` (хвойный лесной `#4d8565`),
     - `earth` (песочно-земляной `#ad8f6e`).
   - Кастомные утилиты в плагине: `.glass-card`, `.glass-card-dark`, `.scrollbar-custom`.

2. **Слой компонентов (`src/css/style.css`):**
   Чтобы не дублировать длинные цепочки классов на повторяющихся элементах (кнопках, карточках, инпутах), в `@layer components` вынесены переиспользуемые классы через `@apply`:
   - `.bento-card` — стеклянные карточки с мягким свечением при наведении;
   - `.ds-btn`, `.ds-btn-primary`, `.ds-btn-sunset`, `.ds-btn-secondary` — единая матрица кнопок;
   - `.ds-kicker` — акцентный заголовок-надпись с градиентной полоской;
   - `.nav-link` и `.nav-link-active` — ссылки навигации с анимированным подчёркиванием;
   - `.v-fade-slide-*` — классы анимации для встроенного компонента `<Transition>` во Vue 3.

### 5. Шпаргалка для защиты: частые вопросы и ответы

- **Почему использовали Vite + Vue 3 на нескольких HTML-страницах, а не чистый HTML/JS?**
  Vite даёт мгновенный сервер разработки (HMR) и собирает `.vue` и Tailwind CSS в оптимизированные минифицированные бандлы. Vue 3 убирает ручную работу с DOM: фильтры, корзина, чат, калькулятор веса и конструктор маршрутов работают реактивно через состояние (`ref`/`computed`), а код остаётся модульным и читаемым.
- **Как компоненты общаются между собой на одной странице (например, кнопка «В корзину» в каталоге и счётчик в шапке)?**
  `SiteHeader.vue` и `InteractiveCatalog.vue` смонтированы как два независимых Vue-приложения на странице `pages/ecommerce.html`. Когда в каталоге меняется количество товаров, `watch` отправляет браузерное событие `window.dispatchEvent(new CustomEvent('tn-cart-updated', { detail: { count } }))`, а `SiteHeader.vue` слушает его и анимирует счётчик корзины.
- **Как работает тёмная тема без «мигания» при загрузке страницы?**
  В `<head>` каждой страницы встроен маленький синхронный `<script>`, который до отрисовки `<body>` проверяет `localStorage.getItem('theme')` (или системную тему `prefers-color-scheme`) и сразу ставит класс `dark` на `<html>`. Далее `SiteHeader.vue` позволяет переключать тему в реальном времени.
- **Почему выбран Tailwind CSS, а не Bootstrap?**
  Bootstrap навязывает готовый «шаблонный» внешний вид компонентов, который сложно глубоко кастомизировать. Tailwind даёт полную свободу дизайна (bento-карточки, градиенты, glassmorphism, кастомная природная палитра) и при сборке оставляет только реально использованные классы.
